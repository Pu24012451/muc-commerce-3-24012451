## 用自己的话回答

- 什么是特征，什么是标签：特征是模型用于预测的输入变量，如使用月数、投诉记录等；标签是模型要预测的目标答案，即用户是否流失。

- 为什么要保留测试集：测试集用于模拟模型面对从未见过的新用户时的表现，客观评估模型的泛化能力，防止模型过拟合。
- 为什么83%准确率仍可能没有用：若多数类本身就占83%，模型只猜多数类也能达到83%准确率，此时准确率无法反映模型有效性，需结合召回率、精确率等指标综合评估。
